# KLH — обратная связь

Трекер KOMPAS Little Helper (CheckSume).

Сообщения приходят из окна «Обратная связь» в КОМПаньоне **зашифрованными**: текст, журнал и
картинки шифруются на компьютере автора открытым ключом разработчиков, прочитать их могут только
разработчики. Здесь видны только тип, номер, версия KLH и шифротекст.

Всё незашифрованное (старые версии программы, отправка в обход) автоматически шифруется копией и
удаляется (`.github/workflows/hide-unsealed.yml`).

| Label | Назначение |
|---|---|
| `idea` | Банк идей |
| `bug` | Баг-трекер |
| `hidden` | Пришло незашифрованным — спрятано |
